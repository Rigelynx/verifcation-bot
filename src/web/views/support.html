resolverlo.

Para problemas de acceso, consulta con los administradores del servidor y comprueba qué rol tienes asignado. Para reportar un fallo del bot o solicitar una revisión de tus datos, utiliza el soporte del propietario.

Contactar con soporte ↗

Si todavía no hay un enlace de soporte publicado, pide a los administradores de tu servidor que contacten con el propietario del bot. Incluye el nombre o ID del servidor y la función afectada; nunca incluyas contraseñas ni claves API.

No veo mi comunidad

Comprueba que el bot esté instalado, que pertenezcas al servidor y que tengas el rol administrativo o de operaciones requerido.

El asistente no está habilitado

Su activación y lista de acceso se configuran desde la consola privada del propietario. La comunidad debe tener también un proveedor disponible.
